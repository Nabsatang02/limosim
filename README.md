LimoSim is a robotics simulation project.

```text
less files
less bloat
less suffering
more empty directories
```

Very optimized.

Such performance.

## Why?

Original repository:

> wow, many files

This repository:

> wow, fewer files

That is the entire project philosophy.

No fancy optimization algorithm.

No machine learning.

No revolutionary architecture.

Just deleting things.

## What was removed?

Unnecessary files and components were removed from the original repository.

If something wasn't needed, it was considered a strong candidate for deletion.

If something was still needed, it was unfortunately allowed to remain.

Very scientific methodology.

## Design Philosophy

The project follows several advanced engineering principles:

1. Have fewer files.
2. Delete unnecessary files.
3. Do not add unnecessary files.
4. If possible, delete another file.
5. Question whether that file really needs to exist.

In other words:

```text
much clean
very minimal
such maintainable
```

## Performance

Does removing files make the robot faster?

Probably not.

Does it make the repository less annoying?

Yes.

Is this a scientifically meaningful benchmark?

No.

But the file tree looks better, so we consider this a success.
